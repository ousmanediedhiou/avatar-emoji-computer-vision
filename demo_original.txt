0) Prérequis

Python 3.10 (64-bit) installé (important pour MediaPipe)
→ Vérifier en PowerShell :

py -V


Une webcam utilisable.

1) Récupérer le projet

2) Créer et activer l’environnement Python

Ouvrir Windows PowerShell, dans le dossier du projet Emoji_Ousmane

# créer un environnement virtuel
py -3.10 -m venv .venv

# (si PowerShell bloque les scripts) autoriser pour la session :
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

# activer l'environnement
.\.venv\Scripts\Activate.ps1

# vérifier qu'on est bien en 64-bit et en 3.10
python -c "import platform,struct;print(platform.python_version(),'bits=',struct.calcsize('P')*8)"


Attendu : 3.10.x bits= 64

3) Installer les dépendances

Toujours dans l’environnement activé ((.venv) au début de la ligne) :

python -m pip install --upgrade pip setuptools wheel
python -m pip install mediapipe opencv-python numpy


Si l’installation de mediapipe échoue, c’est quasi toujours une mauvaise version de Python. Il faut bien 3.10 x64.

4) Lancer le programme
python project_avatar_multi_dnnviz.py
